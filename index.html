About this token & API cost calculator

Estimate how many tokens your text uses and what an API call will cost across providers such as OpenAI (GPT), Anthropic (Claude) and Google (Gemini). It runs in your browser, so your prompt text stays private.

How to use

  1. Paste your prompt or sample text.
  2. See the estimated token count.
  3. Pick a model to see the input and output cost.

Why use it

API pricing is per token and costs add up fast at scale. Estimating tokens and comparing model prices before you build helps you choose the most cost-effective model and budget accurately.

FAQ

How accurate is the token count?

It's a close estimate; exact counts vary slightly by each model's tokenizer.

Does it cover input and output pricing?

Yes — most models price input and output tokens differently, and the calculator reflects that.

Is my text sent to any API?

No — counting is done locally and nothing is uploaded.

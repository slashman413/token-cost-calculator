# 🧮 LLM Token Cost Calculator

> Count tokens and compare API pricing for GPT, Claude, Gemini, DeepSeek and Llama. Free, no signup, and it runs entirely in your browser.

**🔗 Use it: <https://tools.slashmantools.us/token-cost-calculator/>**

## ✨ What it does
- Estimates the token count of any text you paste (GPT-style tokenizer)
- Compares input/output cost across the major hosted models side by side
- Multiplies by expected output tokens and number of calls, so you see the total for a whole job
- Nothing leaves your browser. There is no backend and no tracking of your text

## 📦 Where the code lives
The calculator is maintained in **[free-tools-hub](https://github.com/slashman413/free-tools-hub/tree/main/token-cost-calculator)**,
which builds all Slashman Tools pages from one place. This repo keeps the original
`slashman413.github.io/token-cost-calculator/` URL working: it redirects to the live page,
so old links and bookmarks don't break.

Spotted a wrong price or a missing model? [Open an issue](https://github.com/slashman413/token-cost-calculator/issues) with the provider's pricing link.
